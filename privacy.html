Magnus Confirmations — политика конфиденциальности

Приложение предназначено только для личного использования владельцем. Публичной регистрации и сторонних пользователей нет.

Приложение читает идентификатор и название собственного YouTube-канала владельца, а также сведения о публичных роликах одного отслеживаемого канала. Для каждой карточки сохраняются ролик, черновик комментария, состояние подтверждения и результат отправки. Идентификаторы владельца Telegram, личного чата, сообщения и нажатия кнопки используются для проверки конкретного разрешения и защиты от повторной публикации.

Комментарий передаётся YouTube только после отдельного нажатия владельцем кнопки «отправить». Telegram получает карточки с текстом, ссылкой и сведениями об аккаунте отправителя, а также уведомления о результатах. GitHub предоставляет вычислительную среду Actions и хранение состояния.

OAuth-токены Google и токен Telegram хранятся в зашифрованных GitHub Secrets приватного репозитория. История роликов, черновиков и подтверждений хранится в приватной ветке состояния. Локальные файлы авторизации исключены из Git; они не предназначены для публикации.

В приложении нет рекламы, аналитики посещений или отслеживания для рекламных целей. Данные не продаются и не используются для рекламного профилирования. Google, Telegram и GitHub обрабатывают получаемые ими данные по собственным правилам:
Google: https://policies.google.com/privacy
Telegram: https://telegram.org/privacy
GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

История сохраняется до её удаления владельцем или удаления проекта. Владелец может остановить workflow, удалить историю и секреты, а также отозвать доступ приложения в настройках аккаунта Google. Отзыв доступа не удаляет ранее опубликованные комментарии и сообщения Telegram; ими управляют в соответствующих сервисах.
